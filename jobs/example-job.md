# 例: 文字計数ツールを作らせる

（このファイルは1行スターターがそのまま使うサンプルジョブです。
自分の仕事をやらせるときは、この形式で jobs/ に .md を足してください）

---

次を実装してください。

`counter.py` に、テキストファイルのパスを受け取り行数・単語数・バイト数を
数えて辞書で返す関数 `count(path)` を作ってください。

- 入力ファイルが存在しない場合は FileNotFoundError をそのまま投げる
- 空ファイルは {"lines": 0, "words": 0, "bytes": 0}
- `test_counter.py` に、上記2ケースを含む unittest を書いてください
- **必ず `counter.py` と `test_counter.py` をファイルとして保存してください。
  説明だけの回答は完成ではありません**
- コミットは不要です（人が確認してから行います）
